# 🚀 COMMENCER ICI

## ⚡ Démarrer en 30 secondes

### Étape 1: Lancer les serveurs (2 terminaux)

```powershell
# Terminal 1 - Backend PHP (PowerShell)
cd backend; php -S localhost:8000

# Terminal 2 - Frontend Vite
npm run dev
```

> ⚠️ **Note:** Sur PowerShell, utilisez `;` au lieu de `&&`

### Étape 2: Ouvrir l'interface
```
http://localhost:5173/test-rbac.html
```

### Étape 3: Sélectionner un utilisateur
Choisissez parmi 5 utilisateurs et voyez les permissions s'afficher automatiquement.

### Étape 4: Accéder au Dashboard
Une fois connecté, cliquez sur **"📊 Accéder au Dashboard Admin"** pour voir tous les logs et statistiques.
